# TIME-3185 ([retour](../lynis.md))

Il s'agit d'un problème (Warning) où l'horloge du système n'a pas été synchronisée récemment par systemd-timesyncd. Cela peut notamment provenir d'un intervalle de synchronisation trop important ou d'un problème empêchant la synchronisation.

### Message :

```
! systemd-timesyncd did not synchronized the time recently. [TIME-3185]

https://cisofy.com/lynis/controls/TIME-3185/
```

### Solution :

On commence par créer le répertoire qui permettra de contenir les fichiers de configuration de systemd-timesyncd :
```
sudo mkdir -p /etc/systemd/timesyncd.conf.d
```

Puis d'éditer le fichier ```/etc/systemd/timesyncd.conf.d/60-lynis.conf``` de la manière suivante :
```
[Time]
PollIntervalMinSec=32s
PollIntervalMaxSec=15min
```

De configurer les permissions et le propriétaire du fichier de la manière suivante :
```
sudo chown root:root /etc/systemd/timesyncd.conf.d/60-lynis.conf
sudo chmod 644 /etc/systemd/timesyncd.conf.d/60-lynis.conf
sudo chmod 755 /etc/systemd/timesyncd.conf.d
```

Et enfin, de redémarrer le service :
```
sudo systemctl restart systemd-timesyncd
```
