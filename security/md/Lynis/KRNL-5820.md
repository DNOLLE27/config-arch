# KRNL-5820 ([retour](../lynis.md))

Les « core dumps » sous Linux sont des captures de la mémoire lors du crash d'un logiciel, permettant d'obtenir des informations, notamment lors du débogage.

Mais ces instantanés peuvent contenir des informations sensibles. Il est vivement conseillé, s'ils ne sont pas utilisés, de les désactiver.

### Message :

```
* If not required, consider explicit disabling of core dump in /etc/security/limits.conf file [KRNL-5820]
  - Related resources
    * Article: Understand and configure core dumps on Linux: https://linux-audit.com/software/understand-and-configure-core-dumps-work-on-linux/
    * Website: https://cisofy.com/lynis/controls/KRNL-5820/
```

### Solution :

Il suffit d'éditer le fichier ```/etc/security/limits.conf``` de la manière suivante :
```
*               soft    core            0
*               hard    core            0
```
