# ACCT-9626 ([retour](../lynis.md))

Il s'agit d'installer un outil qui va permettre de recueillir des données sur le système et de réaliser des statistiques pour la résolution de problèmes.

### Message :

```
* Enable sysstat to collect accounting (no results) [ACCT-9626]
    - Related resources
      * Website: https://cisofy.com/lynis/controls/ACCT-9626/
```

### Solution :

Installation de sysstat :
```
sudo pacman -S sysstat
```

Activation et lancement du service :
```
sudo systemctl enable --now sysstat
```
