# TIME-3104 ([retour](../lynis.md))

Il s'agit d'activer un service de synchronisation de l'heure afin de s'assurer que l'horloge du système reste correcte et à jour.

### Message :

```
* Use NTP daemon or NTP client to prevent time issues. [TIME-3104]
    - Related resources
      * Website: https://cisofy.com/lynis/controls/TIME-3104/
```

### Solution :

Activation et lancement du service tinysyncd :
```
sudo systemctl enable --now systemd-timesyncd
```

Pour vérifier que tout fonctionne :
```
timedatectl status
```
