# BANN-7126 ([retour](../lynis.md))

Il s'agit d'ajouter une bannière pour avertir les utilisateurs SSH des accès non autorisés.

### Message :

```
* Add a legal banner to /etc/issue, to warn unauthorized users [BANN-7126]
    - Related resources
      * Article: The real purpose of login banners: https://linux-audit.com/the-real-purpose-of-login-banners-on-linux/
      * Website: https://cisofy.com/lynis/controls/BANN-7126/
```

### Solution :

Il suffit d'ajouter après une nouvelle ligne au fichier ```/etc/issue``` et ```/etc/issue.net``` :
```
WARNING: Unauthorized access to this system is prohibited.
By continuing to use this system, you consent to monitoring and logging.
All activity may be recorded and audited.
```

Et de modifier le fichier ```/etc/ssh/sshd_config``` de la manière suivante :
```
...
Banner /etc/issue
```
