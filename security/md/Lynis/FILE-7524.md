# FILE-7524 ([retour](../lynis.md))

Dans cette analyse, Lynis va détecter les permissions de certains fichiers. S'ils ne correspondent pas à celles attendues, il faudra alors les changer.

### Message :

```
* Consider restricting file permissions [FILE-7524]
    - Details  : See screen output or log file
    - Solution : Use chmod to change file permissions
    - Related resources
      * Website: https://cisofy.com/lynis/controls/FILE-7524/
```

### Solution :

Pour obtenir les fichiers ayant des permissions différentes de celles qu'ils devraient avoir (cela donnera une liste des fichiers et les permissions qu'ils devraient avoir) :
```
sudo lynis show details FILE-7524
```

Voici une liste des permissions que j'ai dû changer personnellement :
```
sudo chmod 600 /etc/cron.deny
sudo chmod 600 /etc/crontab
sudo chmod 600 /etc/ssh/sshd_config
sudo chmod 700 /etc/cron.d
sudo chmod 700 /etc/cron.daily
sudo chmod 700 /etc/cron.hourly
sudo chmod 700 /etc/cron.weekly
sudo chmod 700 /etc/cron.monthly
```
