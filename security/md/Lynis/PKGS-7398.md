# PKGS-7398 ([retour](../lynis.md))

L'objectif est d'installer un outil qui permettra de détecter les paquets installés sur le système présentant des vulnérabilités.

### Message :

```
* Install a package audit tool to determine vulnerable packages [PKGS-7398]
    - Related resources
      * Website: https://cisofy.com/lynis/controls/PKGS-7398/
```

### Solution :

Installation d'arch-audit :
```
sudo pacman -S arch-audit
```

Lancer un audit :
```
arch-audit
```
