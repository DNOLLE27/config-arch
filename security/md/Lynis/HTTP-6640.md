# HTTP-6640 ([retour](../lynis.md))

mod_evasive est une extension pour les serveurs web Apache, permettant de protéger le serveur Web contre les attaques DoS.

### Message :

```
* Install Apache mod_evasive to guard webserver against DoS/brute force attempts [HTTP-6640]
    - Related resources
      * Website: https://cisofy.com/lynis/controls/HTTP-6640/
```

### Solution :

Téléchargement et installation de l'extension :
```
git clone https://github.com/jvdmr/mod_evasive.git
cd mod_evasive
git --no-pager tag --sort=-version:refname

# Choix de la version :
git checkout 2.4.0

sudo apxs -i -a -c mod_evasive24.c
```

Actualisation du serveur Apache :
```
sudo httpd -t
```

Pour vérifier que l'extension est bien prise en compte :
```
sudo httpd -M | grep -i evasive
```

Configuration de l'extension via le fichier ```/etc/httpd/conf/extra/mod_evasive.conf``` :
```
<IfModule evasive_module>
    DOSEnabled true

    DOSHashTableSize 3097

    DOSPageCount 10
    DOSPageInterval 1

    DOSSiteCount 100
    DOSSiteInterval 1

    DOSBlockingPeriod 10

    DOSLogDir "/var/log/httpd/mod_evasive"

    DOSWhitelist 127.0.0.1
    DOSWhitelist ::1
</IfModule>
```

Création du répertoire de logs :
```
sudo install -d -o http -g http -m 750 \
    /var/log/httpd/mod_evasive
```

Inclusion du fichier précédent dans la configuration du ```/etc/httpd/conf/httpd.conf``` :
```
...

Include conf/extra/mod_evasive.conf
```

Actualisation du serveur Apache :
```
sudo httpd -t
```

> [!IMPORTANT]
> À chaque mise à jour, il faudra refaire le build et la configuration.
