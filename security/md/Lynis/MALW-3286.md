# MALW-3286 ([retour](../lynis.md))

L'objectif est d'activer un service qui permettra de mettre régulièrement à jour les bases de données de signatures de malwares de ClamAV.

### Message :

```
* Confirm that freshclam is properly configured and keeps updating the ClamAV database [MALW-3286]
    - Related resources
      * Website: https://cisofy.com/lynis/controls/MALW-3286/
```

### Solution :

Activation et lancement du service de freshclam :
```
sudo systemctl enable --now clamav-freshclam
```
