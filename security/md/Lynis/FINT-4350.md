# FINT-4350 ([retour](../lynis.md))

L'objectif est d'installer un outil qui va permettre de surveiller les modifications apportées aux fichiers présents sur le système.

Aide est un outil qui permet de surveiller les fichiers en conservant, dans une base de données locale, la signature des fichiers.

Nous pourrons configurer les fichiers à surveiller et indiquer quels changements doivent être pris en compte (modification du contenu, ...).

### Message :

```
* Install a file integrity tool to monitor changes to critical and sensitive files [FINT-4350]
    - Related resources
      * Article: Monitoring Linux file access, changes and data modifications: https://linux-audit.com/monitoring-linux-file-access-changes-and-modifications/
      * Article: Monitor for file changes on Linux: https://linux-audit.com/monitor-for-file-system-changes-on-linux/
      * Website: https://cisofy.com/lynis/controls/FINT-4350/
```

### Solution :

Installation des prérequis :
```
sudo pacman -S --needed \
    base-devel git wget gnupg \
    openssl zlib pcre2 libgcrypt \
    libcap acl
```

Téléchargement des fichiers sources et de la signature :
```
wget https://github.com/aide/aide/releases/download/v0.19.3/aide-0.19.3.tar.gz
wget https://github.com/aide/aide/releases/download/v0.19.3/aide-0.19.3.tar.gz.asc
```

Vérification de la signature :
```
gpg --keyserver hkps://keys.openpgp.org \
    --recv-keys 5495CDA17C9AC17AB23841A718EE86386022EF57

gpg --fingerprint 5495CDA17C9AC17AB23841A718EE86386022EF57

gpg --verify aide-0.19.3.tar.gz.asc aide-0.19.3.tar.gz
```

Build :
```
tar xf aide-0.19.3.tar.gz

cd aide-0.19.3

sudo ./configure \
    --prefix=/usr/local \
    --sysconfdir=/etc \
    --localstatedir=/var \
    --with-config_file=/etc/aide.conf \
    --without-nettle \
    --with-gcrypt

sudo make -j"$(nproc)"

sudo make check

sudo make install
```

Création des répertoires pour la base de données et les logs :
```
sudo install -d -o root -g root -m 700 /var/lib/aide
sudo install -d -o root -g root -m 700 /var/log/aide
```

Création du fichier de configuration ```/etc/aide.conf``` :
```
database_in=file:/var/lib/aide/aide.db.gz
database_out=file:/var/lib/aide/aide.db.new.gz
database_new=file:/var/lib/aide/aide.db.new.gz

gzip_dbout=yes

report_url=stdout
report_level=changed_attributes

NORMAL = p+i+n+u+g+s+m+c+sha512
BOOT = p+n+u+g+s+m+c+sha512
DIR = p+i+n+u+g
LOG = p+u+g+n

/boot                       BOOT
/etc                        NORMAL
/usr/bin                    NORMAL
/usr/sbin                   NORMAL
/usr/lib                    NORMAL
/usr/lib64                  NORMAL
/usr/local/bin              NORMAL
/usr/local/sbin             NORMAL
/usr/local/lib              NORMAL
/root                       NORMAL

!/proc
!/sys
!/dev
!/run
!/tmp
!/var/tmp
!/var/cache
!/var/log
!/home/.cache
```

Génération de la base de données :
```
sudo /usr/local/bin/aide --init

sudo mv /var/lib/aide/aide.db.new.gz \
             /var/lib/aide/aide.db.gz
```

Pour lancer une vérification :
```
sudo /usr/local/bin/aide --check
```

Pour mettre à jour la base de données, si un changement est légitime :
```
sudo /usr/local/bin/aide --update

sudo mv /var/lib/aide/aide.db.new.gz \
             /var/lib/aide/aide.db.gz
```

Création d'un timer pour exécuter une vérification toutes les 30 minutes :
```
# /etc/systemd/system/aide-check.service :

[Unit]
Description=AIDE file integrity check
After=local-fs.target

[Service]
Type=oneshot
ExecStart=/usr/local/bin/aide --check
Nice=10
IOSchedulingClass=best-effort
IOSchedulingPriority=7
SuccessExitStatus=1 2 3 4 5 6 7

# /etc/systemd/system/aide-check.timer :

[Unit]
Description=Daily AIDE integrity check

[Timer]
OnCalendar=daily
Persistent=true
RandomizedDelaySec=30m

[Install]
WantedBy=timers.target
```

Activation du timer :
```
sudo systemctl daemon-reload
sudo systemctl enable --now aide-check.timer
```

Pour lancer manuellement une vérification via le service :
```
sudo systemctl start aide-check.service
sudo journalctl -u aide-check.service
```

> [!IMPORTANT]
> À chaque mise à jour, il faudra refaire le build et la configuration.
