# NAME-4028 et NAME-4404 ([retour](../lynis.md))

Il s'agit de définir un nom de domaine DNS/FQDN pour votre système.

### Messages :

```
* Check DNS configuration for the dns domain name [NAME-4028]
    - Related resources
      * Website: https://cisofy.com/lynis/controls/NAME-4028/

* Add the IP name and FQDN to /etc/hosts for proper name resolving [NAME-4404]
    - Related resources
      * Article: Keeping your /etc/hosts file healthy: https://linux-audit.com/is-your-etc-hosts-file-healthy/
      * Website: https://cisofy.com/lynis/controls/NAME-4404/
```

### Solution :

Attribution du domaine au système :
```
sudo hostnamectl set-hostname <hostname>.localdomain
```

Enfin, il faut éditer le fichier ```/etc/hosts``` de la manière suivante :
```
127.0.1.1 <hostname>.localdomain <hostname>
```
