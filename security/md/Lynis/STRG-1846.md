# STRG-1846 ([retour](../lynis.md))

FireWire est une ancienne interface de connexion pour les périphériques externes, aujourd'hui pratiquement plus utilisée. Il est recommandé de la désactiver afin de réduire la surface d'attaque, notamment en empêchant d'éventuels accès non autorisés à la mémoire ou l'utilisation de périphériques FireWire.

### Message :

```
* Disable drivers like firewire storage when not used, to prevent unauthorized storage or data theft [STRG-1846]
    - Related resources
      * Website: https://cisofy.com/lynis/controls/STRG-1846/
```

### Solution :

Il suffit d'éditer le fichier ```/etc/modprobe.d/firewire.conf``` de la manière suivante :
```
blacklist firewire_core
blacklist firewire_ohci
```

Et de reconstruire les images initramfs :
```
sudo mkinitcpio -P
```
