# PHP-2372 et PHP-2376 ([retour](../lynis.md))

Il s'agit ici de désactiver l'affichage des informations de votre serveur PHP ainsi que le téléchargement de données depuis le serveur.

### Messages :

```
* Turn off PHP information exposure [PHP-2372]
    - Details  : expose_php = Off
    - Related resources
      * Website: https://cisofy.com/lynis/controls/PHP-2372/

* Change the allow_url_fopen line to: allow_url_fopen = Off, to disable downloads via PHP [PHP-2376]
    - Related resources
      * Website: https://cisofy.com/lynis/controls/PHP-2376/
```

### Solution :

Il suffit d'éditer le fichier ```/etc/php/php.ini``` de la manière suivante :
```
expose_php = Off
allow_url_fopen = Off
```
