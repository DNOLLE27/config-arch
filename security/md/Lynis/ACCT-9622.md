# ACCT-9622 ([retour](../lynis.md))

L'objectif est d'installer un outil qui permettra de garder un historique des commandes exécutées sur le système. Ainsi, en cas de problème, nous pourrons connaître l'ensemble des commandes qui y ont mené.

> [!IMPORTANT]
> ACCT n'enregistre que les commandes issues d'un binaire, il ne prend donc pas en compte les commandes internes au langage du terminal.

### Message :

```
* Enable process accounting [ACCT-9622]
    - Related resources
      * Website: https://cisofy.com/lynis/controls/ACCT-9622/
```

### Solution :

Installation des prérequis :
```
sudo pacman -S --needed base-devel wget gnupg
```

Téléchargement des fichiers sources et vérification de la signature :
```
wget https://ftp.gnu.org/gnu/acct/acct-6.6.4.tar.gz
wget https://ftp.gnu.org/gnu/acct/acct-6.6.4.tar.gz.sig

gpg --keyserver hkps://keyserver.ubuntu.com \
    --recv-keys 747774305F9DCC9504703CEFB73CBC7708FA8C10

gpg --fingerprint 747774305F9DCC9504703CEFB73CBC7708FA8C10
```

Build :
```
# Extraction : 
tar xf acct-6.6.4.tar.gz
cd acct-6.6.4

# Configuration et build :
sudo ./configure \
    --prefix=/usr/local \
    --sysconfdir=/etc \
    --localstatedir=/var

sudo make -j"$(nproc)"
```

Si jamais vous avez une erreur de cast sur la méthode qsort(), il faut se rendre dans le répertoire du build/des sources (où se trouve le fichier ```sa.c```) et créer une copie du fichier ```sa.c``` :
```
cp sa.c sa.c.bak
```

Puis exécuter :
```
sed -i \
  -e 's/(int (\*)()) compare_user_entry/compare_user_entry/' \
  -e 's/(int (\*)()) compare_sum_entry/compare_sum_entry/' \
  sa.c
```

Et dans ```sa.c```, remplacer :
```
int compare_user_entry(struct hashtab_elem **s1, struct hashtab_elem **s2)
{
  struct user_data *ud1 = hashtab_get_value (*s1);
  struct user_data *ud2 = hashtab_get_value (*s2);

  return compare_stats_entry (&(ud1->s), &(ud2->s));
}

int compare_sum_entry(struct hashtab_elem **s1, struct hashtab_elem **s2)
{
  struct command_data *ud1 = hashtab_get_value (*s1);
  struct command_data *ud2 = hashtab_get_value (*s2);

  return compare_stats_entry (&(ud1->s), &(ud2->s));
}
```

Par :
```
int compare_user_entry(const void *p1, const void *p2)
{
  const struct hashtab_elem * const *s1 = p1;
  const struct hashtab_elem * const *s2 = p2;

  struct user_data *ud1 = hashtab_get_value(*s1);
  struct user_data *ud2 = hashtab_get_value(*s2);

  return compare_stats_entry(&(ud1->s), &(ud2->s));
}

int compare_sum_entry(const void *p1, const void *p2)
{
  const struct hashtab_elem * const *s1 = p1;
  const struct hashtab_elem * const *s2 = p2;

  struct command_data *ud1 = hashtab_get_value(*s1);
  struct command_data *ud2 = hashtab_get_value(*s2);

  return compare_stats_entry(&(ud1->s), &(ud2->s));
}
```

Et :
```
int compare_sum_entry (struct hashtab_elem **, struct hashtab_elem **);
int compare_user_entry (struct hashtab_elem **,
                        struct hashtab_elem **);
```

Par :
```
int compare_sum_entry(const void *, const void *);
int compare_user_entry(const void *, const void *);
```

Puis il suffit de nettoyer le build et de le relancer :
```
sudo make clean
sudo make -j$(nproc)
```

Enfin, de lancer les tests sur le build et de l'installer :
```
sudo make check
sudo make install
```

Pour tester si l'installation c'est bien déroulé :
```
/usr/local/sbin/accton --version
/usr/local/bin/lastcomm --version
```

On vient créer les répertoires pour les logs :
```
sudo install -d -m 0700 -o root -g root /var/log/account
sudo install -m 0600 -o root -g root /dev/null /var/log/account/pacct
```

Ensuite, on vient s'assurer que les chemins vers les commandes utilisés dans le service ```/etc/systemd/system/acct.service``` sont les bons, pour cela, il suffit d'utiliser la commande suivante pour connaître le chemin réel :
```
command -v accton
```

On obtient alors le service suivant :
```
[Unit]
Description=GNU process accounting
Documentation=man:accton(8)
After=local-fs.target
ConditionPathIsReadWrite=/var/log/account

[Service]
Type=oneshot
RemainAfterExit=yes
ExecStart=/usr/local/sbin/accton /var/log/account/pacct
ExecStop=/usr/local/sbin/accton off

[Install]
WantedBy=multi-user.target
```

Il suffit ensuite d'actualiser la liste des services, d'activer et lancer le service d'ACCT :
```
sudo systemctl daemon-reload
sudo systemctl enable --now acct.service
```

Pour lancer manuellement ACCT :
```
sudo accton on
```

Afin d'alléger le stockage des logs de ACCT, nous allons activer la rotation de logs.

Installation des prérequis :
```
sudo pacman -S logrotate
```

Activation et lancement du service :
```
sudo systemctl enable --now logrotate.timer
```

Pour attribuer des règles aux logs d'ACCT, il suffit d'éditer ```/etc/logrotate.d/acct``` de la manière suivante :
```
/var/log/account/pacct {
    daily
    rotate 14
    compress
    delaycompress
    missingok
    notifempty
    create 0600 root root
    sharedscripts
    prerotate
        /usr/local/sbin/accton off
    endscript
    postrotate
        /usr/local/sbin/accton /var/log/account/pacct
    endscript
}
```

Pour tester manuellement la rotation de logs :
```
sudo logrotate --force|--debug /etc/logrotate.d/acct
```

> [!IMPORTANT]
> À chaque mise à jour, il faudra refaire le build et la configuration.
