# ACCT-9630 ([retour](../lynis.md))

Cette suggestion est souvent due au fait que le daemon Audit est lancé sur votre système, mais qu'aucune règle ne lui est définie. Il faut alors en définir quelques-unes.

### Message :

```
* Audit daemon is enabled with an empty ruleset. Disable the daemon or define rules [ACCT-9630]
    - Related resources
      * Website: https://cisofy.com/lynis/controls/ACCT-9630/
```

### Solution :

Il suffit d'éditer le fichier ```/etc/audit/rules.d/hardening.rules``` de la manière suivante :
```
# Comptes
-a always,exit -F path=/etc/passwd -F perm=wa -F key=identity
-a always,exit -F path=/etc/shadow -F perm=wa -F key=identity
-a always,exit -F path=/etc/group -F perm=wa -F key=identity
-a always,exit -F path=/etc/gshadow -F perm=wa -F key=identity

# Sudo
-a always,exit -F path=/etc/sudoers -F perm=wa -F key=sudo
-a always,exit -F dir=/etc/sudoers.d/ -F perm=wa -F key=sudo

# PAM
-a always,exit -F dir=/etc/pam.d/ -F perm=wa -F key=pam

# Audit
-a always,exit -F dir=/var/log/audit/ -F perm=wa -F key=auditlog

# Hostname
-a always,exit -F path=/etc/hostname -F perm=wa -F key=hostname
-a always,exit -F path=/etc/hosts -F perm=wa -F key=hostname

# Modules noyau
-a always,exit -F dir=/usr/lib/modules/ -F perm=wa -F key=modules
```

Et de réactualiser les règles prises en compte par Audit :
```
sudo augenrules --load
sudo auditctl -l
```
