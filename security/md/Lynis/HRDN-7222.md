# HRDN-7222 ([retour](../lynis.md))

L'objectif est de renforcer l'accès aux compilateurs présents sur le système, de manière à l'autoriser uniquement à l'utilisateur root.

### Message :

```
* Harden compilers like restricting access to root user only [HRDN-7222]
    - Related resources
      * Article: Why remove compilers from your system?: https://linux-audit.com/software/why-remove-compilers-from-your-system/
      * Website: https://cisofy.com/lynis/controls/HRDN-7222/
```

### Solution :

Changement des droits et de l'utilisateur/groupe propriétaire :
```
sudo chown root:root /usr/bin/ar \
               /usr/bin/as \
               /usr/bin/ld \
               /usr/bin/nm \
               /usr/bin/objcopy \
               /usr/bin/objdump \
               /usr/bin/strip \
               /usr/bin/g++ \
               /usr/bin/c++ \
               /usr/bin/gcc

sudo chmod 750 /usr/bin/ar \
               /usr/bin/as \
               /usr/bin/ld \
               /usr/bin/nm \
               /usr/bin/objcopy \
               /usr/bin/objdump \
               /usr/bin/strip \
               /usr/bin/g++ \
               /usr/bin/c++ \
               /usr/bin/gcc
```

Création du répertoire pour les hooks pacman :
```
sudo mkdir -p /etc/pacman.d/hooks
```

Création d'un hook permettant de réattribuer les permissions sur les compilateurs lors de la mise à jour de ces derniers (```/etc/pacman.d/hooks/harden-binutils.hook```) :
```
[Trigger]
Operation = Install
Operation = Upgrade
Type = Package
Target = gcc

[Action]
Description = Restrict compiler and binutils permissions
When = PostTransaction
Exec = /usr/bin/sh -c 'chmod 750 /usr/bin/ar /usr/bin/as /usr/bin/ld /usr/bin/nm /usr/bin/objcopy /usr/bin/objdump /usr/bin/strip /usr/bin/g++ /usr/bin/c++ /usr/bin/gcc'
```
