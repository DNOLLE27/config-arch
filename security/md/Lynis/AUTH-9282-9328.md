# AUTH-9282 et AUTH-9328 ([retour](../lynis.md))

Il s'agit ici d'un ensemble de règles relatives aux comptes utilisateurs du système, visant à forcer le changement des mots de passe à intervalles réguliers, ainsi qu'à la configuration de l'umask, permettant de contrôler les droits par défaut lorsqu'un utilisateur crée un répertoire ou un fichier.

### Messages :

```
* When possible set expire dates for all password protected accounts [AUTH-9282]
    - Related resources
      * Website: https://cisofy.com/lynis/controls/AUTH-9282/

* Configure minimum password age in /etc/login.defs [AUTH-9286]
    - Related resources
      * Article: Configure minimum password length for Linux systems: https://linux-audit.com/configure-the-minimum-password-length-on-linux-systems/
      * Website: https://cisofy.com/lynis/controls/AUTH-9286/

* Configure maximum password age in /etc/login.defs [AUTH-9286]
    - Related resources
      * Article: Configure minimum password length for Linux systems: https://linux-audit.com/configure-the-minimum-password-length-on-linux-systems/
      * Website: https://cisofy.com/lynis/controls/AUTH-9286/

* Default umask in /etc/login.defs could be more strict like 027 [AUTH-9328]
    - Related resources
      * Article: Set default file permissions on Linux with umask: https://linux-audit.com/filesystems/file-permissions/set-default-file-permissions-with-umask/
      * Website: https://cisofy.com/lynis/controls/AUTH-9328/
```

### Solution :

Il suffit d'éditer le fichier ```/etc/login.defs``` de la manière suivante :
```
PASS_MAX_DAYS   365
PASS_MIN_DAYS   1
PASS_WARN_AGE   14
UMASK           027
```

Et pour appliquer les règles précédentes relatives au mot de passe à votre compte utilisateur :
```
sudo chage -M 365 -m 1 -W 14 <username>
```
